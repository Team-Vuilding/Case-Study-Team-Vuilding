# Vercel Web Design Guidelines

Invoke as `$vercel-web-design-guidelines`. This aliases the installed `web-design-guidelines` skill.

Read [the upstream instructions](references/upstream-skill.md), then fetch current rules from `https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md` with available HTTP or web tools. Review the requested files and return actionable file/line findings. For Core Web Vitals, read [the local quality profile](../system-performance-and-quality/SKILL.md).

These are review instructions, not an executable linter or measured performance results.
